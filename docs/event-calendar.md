## 财报与状态边界

- 复用 `us-megacaps.json` 小型快照，无需加载大型技术行情。`technical-events.json` 已核对，其公司事件主要重复该快照，故不重复加载。
- `lastReportedDate` 是 Nasdaq 聚合记录，显示“已报告 · 聚合记录”；不声称已经审阅公司报告。
- `nextEarningsDate` 来自既有更新脚本的 StockAnalysis 统计页抓取，显示“预计日期”，明确未获公司官方确认；所有财报日期均为仅日期，不猜测盘前、盘后或时刻。
- 缺失或无效的下次日期单列“待定”，不编造占位日期，不导出为 ICS 事件。时间未知与日期未知分别处理。
- 宏观计划的时刻经过后仅显示“计划时间已过 · 发布待核验”，不修改状态为已发布，不显示猜测实际值。未采用旧 `technical-events.json` 中仅随日期推进的 `released` 标签作为发布证据。
- 宏观关联覆盖明确列出的跨资产标识及 `us-` 美股自选；这只是研究范围，不是事件影响或因果预测。财报只按股票标识精确匹配。

## 时间、导出与维护

- 纽约当地时刻使用原生 `Intl` 的 IANA 时区数据换算 UTC；拒绝夏令时切换造成的不存在或重复时刻。北京、纽约与 UTC 只是显示选项，日期范围按当前显示时区筛选。
- 仅日期事件保留来源日历日期，不跨时区偏移。ICS 使用 `DTSTART;VALUE=DATE` 与次日排他的 `DTEND`；定时事件使用 UTC `DTSTART`，不编造事件持续时长。
- ICS UID 来自稳定事件标识；重复事件去重。输出使用 CRLF、UTF-8 75字节折行，并转义反斜线、逗号、分号和换行。源 URL 限定 HTTP(S)，ID 不允许内容注入。
- ICS 文件是导出快照，不是实时订阅。宏观核验超过14天或筛选超出覆盖范围时，页面提示回到官方来源确认。
- 更新宏观日程时复核官方网页/ICS，修正 `macroCalendarCheckedAt` 与覆盖截止；不能仅延长覆盖日期。后续可让既有 `update-technical-events.mjs` 增加 BLS、源时区、明确时间精度、核验日期和实际发布证据字段，再替换手工维护数据；本轮未更改共享更新脚本。
