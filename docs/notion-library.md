# Notion 分类总结

入口：`/notion-library`。有执行材料时默认展示成果工作台，可切换阅读按主题合并的正文、内容要点、整理建议和待核实点。原文链接仅在章节末尾用于来源追溯；逐条资料索引与备份管理收进次要折叠区域。

## 数据范围

页面自身不连接 Notion。通过连接器人工整理并脱敏的 JSON 快照，由使用者在页面选择文件，预览后合并导入。导入后按来源页面 ID 更新，其他已存条目保留；不会写回 Notion。

个人快照不应放入 `src/`、`public/`、Git 或构建目录。源代码及测试仅包含通用功能和虚构测试数据。

## 保存与备份

本地 `npm run dev` 的分类总结固定读取 `.local-data/notion/notion-library.json`，不以账号或浏览器旧快照替换。开发服务器通过仅开发环境存在的 `/web3/__local/notion-library.json` 提供文件，响应不缓存；刷新页面重读。导入及本人补充仅保留在本页，须导出 JSON 并替换本地文件以持久保留。该目录被 Git 忽略，不复制到生产构建，生产环境仍沿用下述账号/浏览器存储机制。

未登录时使用 `useLocalRecord`，存储键为 `market-desk-notion-library-v1`。跨标签页冲突、存储错误及不可读数据均阻止覆盖。本机旧资料不会在登录后自动上传；清理站点数据前仍应导出 JSON 备份，浏览器存储未加密。

登录后页面读取当前账号私有云资料，页首显示状态。修改本人补充或导入文件后，须点击“保存到账号”；没有自动写入、轮询或 Notion 同步。账号云端为空时可手动把本机旧资料载入，再点击保存。退出或切换账号会清除当前页面的云端资料；其他浏览器登录同一账号后可读取已保存版本。切换会话的旧标签页会锁定云端保存并要求刷新。

Worker 的 `GET/PUT /api/notion-library` 均要求有效登录，按服务端认证用户 ID 访问 D1，响应 `no-store`。迁移 `worker/migrations/0039_notion_library.sql` 创建每用户一行的私有资料和版本号；写入按版本条件更新，409 冲突不会覆盖新版本。请求按 2MB 限制并复用导入校验。该功能目前仅完成本地开发，尚未部署或上传个人快照。

## 导入协议

定义见 `src/types/notion-library.ts`。版本为1，文件最大2MB，最多1000条。旧版文件兼容；可选 `report` 字段存放跨页面主题总结，包括总览、读取统计、边界、最多30个章节及其正文、要点、建议、分歧和来源ID。来源ID必须对应同一文件内的资料条目。旧文件合并不丢弃已有总结，新总结会更新正文。

每条包含标题、主题、摘要、整理建议、来源更新时间、Notion原文地址，以及可选外链和站内入口。只接受HTTPS外链、无认证或查询参数的Notion来源地址和允许的站内路由。页面使用Vue文本渲染，不执行导入内容中的HTML。未知字段在校验时丢弃。

用 `node --test tests/notion-library.test.mjs` 验证校验、链接限制、合并幂等和搜索行为。

## 执行成果

章节可选 `workProducts`（最多30项），逐项关联原建议 `actionIndex`。每项包括材料标题、结论、三类状态、表格、继续推进说明和本人补充。状态为材料已整理、待本人补充、待外部核验，不代表真实世界事项办结；导入校验拒绝越界建议编号、不齐的表格列和未知状态。来源仍继承所在章节。

本人补充在未登录时保存在当前浏览器，登录时先保留在本页，点击账号保存后才进入云端；导出包含这些补充。导入新总结会整体替换总结及其补充，导入前先备份。旧版无执行材料仍展示分类正文。

产品方向本轮仅整理候选构想、验证说明与待补资料，不提供工具原型或推进软件开发。

## 资产规划合并入口

`/million-action-plan` 重定向至 `/notion-library?chapter=wealth`，侧栏只保留Notion总入口。公开用途目录以 `NotionWealthPlan.vue` 展示于资产规划章节：10类57项（原50项保留、5项深化、7项新增），资金区间示例与原机构来源随内容保留。支持分类和全文筛选；个人需求与办理准备收在同章折叠区域，不另建重复清单。

公开数据仍在 `million-action-plan.json` 维护一份。没有Notion快照时也能看到公开资产章节；导入私人总结后按章节ID合并展示，不覆盖私人原文、来源和补充记录。其他Notion章节和现有备份协议不变。原目录机构条款没有在本轮全部重新核验。
