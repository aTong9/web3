# 组合复盘

入口 `/portfolio-review`。记录个人组合的估值快照与外部资金流，查看区间净收益、Modified Dietz 连乘估算收益率、最新分类配置和观察点最大回撤。数据仅保存在当前浏览器的 `market-desk-portfolio-review-v1`，不接入券商账户或自动获取行情。

## 录入约定

- 整本数据使用 CNY、USD、HKD 或 EUR 中的一种币种；保存首条快照或流水后锁定，不做自动换汇。
- 每个日期最多一个快照，填写当天**所有外部流水入账后的期末组合总价值**，含现金。当天流水视为发生在当日投资收益之后，不能拿入金前余额作为当天最终快照。
- 快照持仓分现金、股票、基金、债券、加密资产和其他六类。金额是估值而非份额，允许为零，最多两位小数；不支持负持仓。空持仓快照表示零估值。
- 外部流水金额必须为正，以存入 / 取出决定方向。只有组合与外界之间的资金转移才是外部流：保留在组合中的现金分红、投资费用、买卖资产与内部换仓均不应再次记为存入或取出。
- “从个人资产读取可投资资产”只读取已保存的 FIRE 数据中的 `investable` 项。自住房、其他资产和负债均排除，不进行债务净额计算。用户确认后，仅替换当前新快照的持仓草稿，分类统一填“其他”，沿用草稿日期。需要逐项检查估值、分类、币种和小数后手动保存；不会更新原个人资产或 FIRE 记录。已有记录或流水草稿与来源币种不符时拒绝混币。

例如，期初组合 100，期末前一天外部存入 20，期末全部资产和现金价值 125。期末快照应填 125，资金流单独记录存入 20；区间净收益是 5，而不是 25。

## 收益与回撤

相邻快照构成一个区间，`startDate < flowDate <= endDate` 的流水纳入该区间。存入为正、取出为负。首个快照当日及以前、最新快照之后的流水保留，但不计入当前完整统计区间，页面显示被排除条数。

```
区间净收益 = 期末估值 − 期初估值 − 净资金流
流水权重 = (区间结束日期 − 流水日期) / 区间天数
加权资本 = 期初估值 + Σ(流水权重 × 带符号外部流水)
Modified Dietz 区间收益率 = 区间净收益 / 加权资本
表现指数 = 前一指数 × (1 + 本区间收益率)，起点为 100
观察点回撤 = 当前指数 / 此前最高指数 − 1
```

末日流水权重为零。各区间收益率连乘得到整段估算表现，整段净收益直接以起终点估值减去净外部存入计算。最新配置变化为最新快照权重减去前一个快照权重，单位是百分点，不是百分比收益。

加权资本不大于零、区间收益率低于 −100% 或指数超出有效数值范围时，相关收益率、指数和回撤显示缺失，不补零。−100% 是合法结果，指数可为零。初值为零不意味着永远不可算：期中入金产生正加权资本时可计算。只有一个快照时没有区间收益率和最大回撤。

这是按日权重的 Modified Dietz 估算，**不是精确时间加权收益率**。大额资金流和高波动会增加估算误差。回撤仅比较已有快照上的收益指数，**不是快照间真实最大回撤**；增加快照可增加观察点，不能保证捕获所有波动。本工具用于记录与复盘，不构成投资建议或正式业绩认证。

公式及日内现金流处理依据：[GIPS Standards Handbook for Firms](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)；核验日期 2026-09-26。项目采用“当日收益后记外部流水”的一致约定。

## 保存与备份

页面使用共享 `useLocalRecord`，写入成功才更新已保存状态。存储满、不可用或其他标签页写入冲突时保留草稿，损坏的原始存储不会被覆盖。跨标签页冲突后重新载入也保留草稿；旧编辑若对应记录已变化，必须确认才覆盖新版本；已删除记录不能被旧草稿自动恢复。币种变化时拒绝原币种草稿继续保存，并提供明确的清空草稿选项。

两种编辑器各自保留草稿，切换编辑器不会丢失另一份草稿。删除快照或流水、切换同类编辑对象、清空草稿和带草稿离页均有确认；删除快照不会删除流水，而会重新计算区间。浏览器刷新或关闭使用原生未保存提醒。

导出包含整个已保存组合，不含未保存草稿。导入先严格校验 10 MB 以内的备份，再确认整体替换及清空草稿；坏文件与保存失败均保留原数据。最多 1,000 个快照、每个 200 项持仓、5,000 条外部流水；单个快照总额和所有流水绝对金额合计不得超过 1 万亿，保证金额计算在安全分币范围内。组合区域加 `ph-no-capture`，排除现有 PostHog 自动交互采集和会话回放。
