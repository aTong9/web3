# 我的研究台

入口：`/research-workspace`，侧边栏「总览 → 我的研究台」。

## 使用流程

1. 在自选资产中选择已有研究目录中的资产，填写分组和关注理由。当前目录来自跨资产快照与美股公司快照。
2. 从关注卡片打开对应走势与预警、关键词资讯检索或量化页面。资产没有技术图时不显示走势图入口。
3. 点击「写研究笔记」，填写观点、来源、失效条件和复查日期。跟踪中的笔记在复查日期当天及之后进入「待复查」。
4. 复查后编辑笔记，记录结论，将状态改为「已复盘」或「已失效」。状态由用户判断，不自动评价收益或判断对错。
5. 量化模拟账本中的「记录复盘」会带入资产与记录 ID。笔记保留引用，账本负责交易；不会因编辑笔记创建、关闭或修改交易。

## 数据与报价

- 本地存储键：`market-desk-research-workspace-v1`。记录不上传到服务器，也不跨浏览器或设备自动同步。
- 使用原有行情接口，最多请求当前自选列表中前 25 个具备同标的报价映射的资产；其他条目显示日期明确的快照。
- 股指保留点位单位。广义美元指数、NASDAQ Euro 50、黄金策略指数和原油现货不混用 DXY、STOXX50 或期货报价。
- 报价来源与快照来源分别展示。最新报价仍可能延迟、过期或不可用，以页面状态和时间为准。
- 新闻链接只是关键词检索，可能无结果；技术预警沿用现有页面与权限。

## 保存、备份和恢复

- 点击保存后，浏览器存储写入成功才更新已保存列表；存储失败时草稿保留。
- 新建时遇到已关注资产会要求确认替换，避免无意覆盖原关注理由。
- 编辑过程中若导入或另一标签页修改同一记录，再保存旧草稿会要求确认替换。离开页面或刷新时，有未保存草稿会请求确认。
- 导出得到完整版本 1 JSON。导入先验证结构、重复 ID、日期和来源 URL；任一记录无效则整份拒绝，不写入部分数据。
- 导入采用合并：自选按资产 ID、笔记按笔记 ID，保留更新时间较新的记录。不会因备份中缺少某条记录而删除本地内容；导入旧备份可能恢复已经删除的记录。
- 未知或已下线资产的历史笔记会保留。已损坏的本地数据不会被空记录覆盖，恢复访问或修复原始 JSON 后可重新载入。
- 文件导入上限 30 MiB，解析内容不超过一千万字符；存储容量受浏览器限制。导出备份后再清理浏览器或更换设备。
- 记录只保存当前版本，不保存每次编辑的历史。模拟记录 ID 是引用，不保证被删除的账本条目仍可访问。

## 实现与验证

- `src/views/ResearchWorkspaceView.vue`：自选、笔记、复查、备份与错误状态。
- `src/utils/research-assets.ts`：现有数据目录及同标的行情映射。
- `src/utils/research-workspace.ts`：输入验证、合并和按本地日历日期判断复查。
- `src/composables/use-research-workspace.ts`：持久化与已变化标签页的写入冲突检测。
- `tests/research-workspace.test.mjs`：坏输入、安全 URL、日期、去重、合并、存储故障、冲突和资产映射回归。

localStorage 比较可发现已经发生的跨标签页变化，但不是跨进程原子事务；当前按个人本机使用设计，未引入云同步。
