# 资源导航补充：利率、债券与原始披露

核对日期：2026-10-15。新增 8 条，新增「市场资讯 · 利率与债券」分类，其余沿用原分类。

优先级：先补固定收益研究的一手入口，再补境内与香港公司披露及宏观发布日历。只更新目录，不接入行情或交易接口。

| 资源与来源 | 用途与限制 |
| --- | --- |
| [纽约联储 SOFR 隔夜融资利率](https://www.newyorkfed.org/markets/reference-rates/sofr) | 纽约联储官方担保隔夜融资利率｜观察以美国国债作抵押的隔夜现金融资成本；属于历史交易基准，不等于个人可获得的存款或投资收益率。 |
| [FINRA 固定收益数据](https://www.finra.org/finra-data/fixed-income) | 美国债券研究入口｜按 TRACE 代码或 CUSIP 查询证券与成交资料；使用须接受数据协议，历史成交不等于当前可执行报价，专业数据订阅另有条件。 |
| [TreasuryDirect 美国国债拍卖](https://www.treasurydirect.gov/auctions/) | 美国财政部国债拍卖资料｜查看发行流程、未来拍卖、近期结果及历史查询；区分票面利率、拍卖收益率与二级市场价格，购买资格另行核对。 |
| [中国债券信息网 · 中债数据](https://www.chinabond.com.cn/) | 中央结算公司债券信息入口｜查找中债曲线、估值及债券市场资料；不同数据服务权限和使用条件不同，估值与曲线不等于实际成交报价。 |
| [BLS 经济数据发布日历](https://www.bls.gov/schedule/news_release/) | 美国劳工统计局官方日历｜核对 CPI、就业与生产者价格等数据的发布时间；以美国东部时间为准，日程可能调整。 |
| [美联储 FOMC 会议与纪要](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) | 美联储官方政策资料｜按会议日期查看声明、会议纪要及可用的经济预测；纪要与决议发布时间不同，须区分已发布资料和未来日程。 |
| [巨潮资讯 · 上市公司公告](https://www.cninfo.com.cn/) | 境内上市公司信息披露检索入口｜查找年报、半年报及临时公告；按证券代码、公告日期与更正版本核对原始文件。 |
| [港交所披露易 HKEXnews](https://www.hkexnews.hk/index.htm) | 港交所披露检索入口｜查询上市公司公告、财务报告与权益披露；核对股份代码、文件语言及发布日期，注意后续补充和更正。 |

核验范围：逐项打开上述入口并核对页面内容或检索导航；未登录、未验证付费功能或运行第三方 API。BLS 使用滚动日历地址，核验时跳转到当月页面。未收录本次访问返回 404 的美国财政部利率页面及返回 403 的 EMMA 入口，避免将未验证的访问状态记为可用。未全面巡检存量链接。

## 第二批：中国市场基金、指数与投资者保护

新增 8 条；新增「市场资讯 · 基金与指数」分类，其余归入现有消费金融核验和财商基础分类。

| 资源与官方来源 | 用途与限制 |
| --- | --- |
| [中证指数 · 指数资料](https://www.csindex.com.cn/) | 中证指数公司官方入口｜查阅指数资料、编制方案及调整公告；区分价格与全收益口径，指数表现不等于基金扣费后收益，页面需启用 JavaScript。 |
| [国证指数 · 指数与产品](https://www.cnindex.com.cn/) | 深圳证券信息有限公司指数入口｜浏览指数、相关产品及样本调整公告；比较前核对编制规则、样本生效日期与收益口径。 |
| [恒生指数 · 指数概览](https://www.hsi.com.hk/zh-cn/indexes/) | 恒生指数公司官方中文资料｜查阅指数系列、报告及编算方法；部分资料需账户或另有使用条件，区分价格与股息累计口径，页面需启用 JavaScript。 |
| [上交所 · 最新基金公告](https://www.sse.com.cn/disclosure/fund/announcement/) | 上海证券交易所基金披露入口｜按基金代码与日期检索相关公告；核对产品全名、公告版本及适用日期，不将交易价格直接视为基金净值。 |
| [上交所 · 公募 REITs 公告](https://www.sse.com.cn/reits/announcements/info/) | 上海证券交易所 REITs 公告检索｜按代码、标题与时间查询原始披露；关注底层资产、运营与分派文件，历史分派不保证未来收益。 |
| [香港证监会 · 持牌人公众纪录册](https://apps.sfc.hk/publicregWeb/searchByName?locale=zh) | 香港证监会官方查询｜按名称、牌照类别及业务活动核验持牌人和注册机构；核对获准活动与官方联系方式，持牌不代表产品保本或收益保证。 |
| [香港证监会 · 无牌公司及可疑网站](https://www.sfc.hk/TC/alert-list) | 香港证监会警示资料｜检索无牌公司及可疑网站线索；名单并非完整清单，未列名不代表安全，须同时核对持牌纪录与实际网站域名。 |
| [香港投委会 · 理财与投资教育](https://www.ifec.org.hk/web/tc/index.page) | 香港投资者及理财教育委员会中文入口｜学习预算、储蓄、退休规划、投资产品与防骗知识；制度和产品以香港为主，使用计算工具时核对假设。 |

核验范围：上交所基金及 REITs 入口由交易所站内导航交叉确认；香港证监会查询表单、警示列表与投委会目录可读取。国证主页可读取导航及调整公告，未验证其表格下载。中证及恒生入口依赖 JavaScript，本次直接读取只返回应用壳；另以官方搜索索引、中证编制方案文件及交易所链接交叉核对身份和资料用途，未验证浏览器交互、成份股下载或付费功能。恒生采用当前简体中文指数概览地址。

证监会基金电子披露平台与深交所基金公告入口重试仍超时，本批暂不收录；超时不代表网站已停运。未全面检查存量资源。
