六项分别补充流量捕获回放、多协议 Java 网关、关系型 CMDB/ITSM、专业实验室信息管理、跨主机游戏服务管理和多人照片图库。它们与各分类现有七项形成明确功能增量；纳入目录时应保留录制流量脱敏、网关入口安全、CMDB 权限、医疗非诊断与合规部署、Agent 权限以及照片元数据和人像隐私边界。
