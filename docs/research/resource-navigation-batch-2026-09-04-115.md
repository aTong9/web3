## IELTS 官方评分详解 — 语言学习 · IELTS 官方备考

[IELTS scoring in detail](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)公开可读，无需账户，介绍总分及分项分数、分档含义和总分舍入例子。页面强调听读原始分换算会随试卷略有差异，接收机构可自行决定接受成绩的期限。

与目录中的样题、IELTS Ready、IDP App 不同，本条针对理解评分规则而非重复练习产品；不把自评作为考试成绩，不承诺提分，也不将官方网页材料视为开源内容。

```yaml

```

## TOEIC — 语言学习 · 英语国际证书

[ETS 官方首页](https://www.ets.org/toeic.html)介绍职场英语测评及相关资源；[听读考试说明](https://www.ets.org/toeic/about/listening-reading.html)定位于工作场景的听力与阅读能力，而非把所有 TOEIC 项目视为同一四技能测试。

[ETS 报名说明](https://www.ets.org/toeic/test-takers/register.html)要求按国家/地区向当地 EPN 查询考试安排，区分听读、口语写作和 Bridge；[考生资源](https://www.ets.org/toeic/test-takers.html)也区分机构考试与公开考试。目录只提供入口，费用应向当地官方核对，不作全球统一报价或免费考试承诺。认可范围须由目标雇主/学校确认，不声称任何项目通用于移民。

```yaml
title: TOEIC
logo: finance.png
url: https://www.ets.org/toeic.html
description: ETS 托业职场英语考试入口｜了解听读、口语写作等测评与备考资源；报名安排及费用向当地官方核对，认可要求以目标雇主或学校为准。
```
