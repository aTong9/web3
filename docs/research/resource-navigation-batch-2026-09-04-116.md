## 加拿大移民代表资格核验 — 语言学习 · 英语国家永居移民

[加拿大 IRCC 官方说明](https://www.canada.ca/en/immigration-refugees-citizenship/services/immigration-citizenship-representative/choose/authorized.html)可直接读取，提供移民顾问监管机构、各省/地区律师协会及魁北克公证人核验入口，并提醒核对良好执业状态。区别于已有加拿大移民路径概览，本条解决代理资格核验；不作具体代理推荐或结果担保。阅读无需账户，未进一步提交姓名查询或联络代表。

## 新加坡永久居民再入境许可 — 语言学习 · 中文地区永居移民

[ICA 官方申请/续期 REP 页面](https://www.ica.gov.sg/reside/PR/apply-REP)可直接读取，介绍永久居民离境期间身份维持、护照资料更新、申请及费用，链接现行规则 FAQ。不同于永久居留首次申请或公民申请。

页面涉及新版规定与多种场景，不在目录硬编码日数、费用或永久居民丧失条件；提醒出行前核对个人情况与现行规定，避免把永居身份当作无限制出入境许可。公开说明无需登录，实际线上办理使用官方电子服务；未进入服务、上传证件或付款。

```yaml
title: 新加坡永久居民再入境许可
logo: finance.png
url: https://www.ica.gov.sg/reside/PR/apply-REP
description: 新加坡 ICA 再入境许可 REP 指引｜供永久居民核对离境、续期及护照资料更新手续；出行前查阅现行条件与费用，不代表自动续期或身份保障。
```

## 日本 FRESC 在留咨询 — 语言学习 · 日本永住入籍

[出入国在留管理厅官方 FRESC 页面](https://www.moj.go.jp/isa/support/fresc/fresc01.html)直接抓取返回 403；同一官方页面搜索索引可读，显示政府机构集中提供在留、劳动与法律咨询窗口，东京入管提供预约制对面/在线在留咨询。另以[官方咨询专页](https://www.moj.go.jp/isa/support/fresc/fresc_2.1.html?hl=en)索引交叉核对预约说明。

收录为程序咨询入口，与已有生活支援资料门户、永住许可及国籍条款不同。只能声明官方索引证据，不能宣称现场服务、预约系统或实时网页已实测。咨询不等于受理所有手续或批准申请；不写入个案资格、费用或时效承诺。未预约、拨号或提交资料。

```yaml

```
