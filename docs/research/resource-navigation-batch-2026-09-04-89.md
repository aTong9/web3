## 1. 语言沟通：Easy Languages

- [官方首页](https://www.easy-languages.org/)说明以街头访谈、日常对话视频及播客学习真实语言，核心内容免费；转录稿、练习等额外材料面向支持会员，不将全部服务描述为免费。
- [官方语言目录](https://www.easy-languages.org/our-languages)列出英语、德语、法语、西语、普通话等项目，并列有粤语、马来语等播放列表；不同语种拥有的频道和材料规模不同。
- 网站导航为英语，内容语言随项目而异；视频入口多依赖 YouTube，未核验各地区播放可达性，也不承诺所有内容具备同样的字幕或课程等级。

## 2. 写作研究：UW-Madison Writer's Handbook

- [大学写作中心官方手册](https://writing.wisc.edu/handbook/)公开提供英文教学资料，覆盖学术写作、职业写作、文章结构、语法及引用，不需账户即可阅读入口内容。
- 同页标明 CC BY-NC-SA 4.0：允许非商业改编，须署名并以相同许可分享。
- 官方提醒不同作业与教师要求不同，通用指南不一定适配具体情境；手册与个别辅导是不同服务，未声称全球读者可预约辅导。

```yaml
- title: UW-Madison Writer's Handbook
  logo: finance.png
  url: https://writing.wisc.edu/handbook/
  description: 威斯康星大学英文写作手册｜免费学习学术与职业写作、结构、语法和引用；采用 CC BY-NC-SA 4.0，具体格式仍须遵循课程或投稿要求。
```

## 3. 电影创作：Learn About Film

- [作者官方主页](https://learnaboutfilm.com/)由电影教育者 Tom Barrance 发布，明确网站免费；涵盖短片策划、拍摄、剪辑、镜头叙事及手机制作，页面为英语。
- 同页提供收费电子书及培训入口，不能将配套产品视为免费；不记录可能变动的金额。
